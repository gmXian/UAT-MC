# UAT-MC

This repository is the official implementation of:

**Band Together: Untargeted Adversarial Training with Multimodal Coordination against Evasion-based Promotion Attacks**

> Code will be released soon.

## Overview

UAT-MC is an adversarial training framework designed to improve the robustness of multimodal recommender systems against evasion-based promotion attacks. The method introduces untargeted adversarial training with multimodal coordination to enhance robustness under arbitrary attack directions while mitigating cross-modal conflicts during adversarial optimization.
